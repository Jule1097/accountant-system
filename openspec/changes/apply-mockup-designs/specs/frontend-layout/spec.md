## ADDED Requirements

### Requirement: Active Sidebar Navigation Highlighting
The system SHALL highlight the currently active sidebar navigation item using the brand active styling.

#### Scenario: Active route highlights sidebar item
- **WHEN** the user is on a route (e.g., Ventas)
- **THEN** the corresponding sidebar item displays white text (`#FFFFFF`, font weight 500) and brand orange icon (`#FF5C00`)
- **AND** the sidebar item background is set to secondary accent background (`#1A1A1D`) with rounded corners (`8px`)
